About TrendScout

TrendScout is a market research application designed to analyse publicly available Etsy marketplace information. It aims to identify emerging product trends, monitor listing activity, evaluate shop performance indicators and track changes in product popularity.

Our Purpose

TrendScout supports independent commercial research and data-driven product decisions by helping identify potential marketplace opportunities.

Data and API Usage

The application is intended to use Etsy's approved API endpoints and comply with Etsy's API Terms of Use and applicable developer requirements.
